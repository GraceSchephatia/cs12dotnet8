# C# 12 and .NET 8 – Learning Project

This repository contains my hands-on learning work while coding along with the book  
**_C# 12 and .NET 8 – Modern Cross-Platform Development Fundamentals_** by **Mark J. Price**.

The goal of this repository is to deepen my understanding of modern .NET development by
building applications and examples using **C# 12**, **.NET 8**, **ASP.NET Core 8**, **Blazor**, and **Entity Framework Core 8**.
